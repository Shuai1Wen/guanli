# Failure Promotion Protocol

The system may learn automatically **inside a project**, but global Skill rules must not self-modify from one anecdote.

## Project-level adaptation
A logged failure becomes an immediate local guardrail if:
- its cause is understood;
- the preventive rule is explicit;
- the future trigger is recognizable.

The next run should read relevant open failure records.

## Global promotion candidate
Promote a failure pattern to a candidate when either:
1. the same `pattern_code` appears in at least **two independent projects**, or
2. one project records a **P0** failure that can invalidate research integrity or the paper's central claim.

## Global rule update
Do not edit Skill rules automatically. Instead:
1. aggregate promotion candidates;
2. propose the smallest rule change;
3. run frozen behavioral regression cases plus at least one real-project replay;
4. accept only if the change improves the target failure without degrading narrow-task execution.

This avoids overfitting the suite to one project.
