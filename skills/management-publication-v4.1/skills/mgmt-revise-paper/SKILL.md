# Revise Toward Publication

Interpret feedback at the deepest level that changes the paper, then act.

## Source honesty

Use the actual advisor/reviewer wording. Do not invent comments, promised analyses, or completed results.

## Translate deep comments

Typical meanings:
- "根没扎下去" → academic mountain + substantive anchor are not established.
- "为什么研究这个" → problem origin/Paper Thesis is weak.
- "这个变量是不是这回事" → research object / construct / data meaning is misaligned.
- "五个问题太多" → recover one core RQ and demote steps.
- "方法讲得很多" → method is not solving a known scholarly difficulty.
- "你的发现和别人有什么不同" → belief update/literature dialogue is missing.
- "故事没讲好" → rebuild problem → mechanism → evidence → knowledge update; do not add rhetoric.

## Prioritize by publication impact

1. research object / field / anchor / core question;
2. theory / construct / data / design;
3. decisive evidence;
4. structure;
5. prose.

Do not polish sections that will disappear after redesign.

## Use state change explicitly

If feedback changes a frozen field, issue `RESET_REQUEST` and update `PAPER_STATE.md` only after the change is accepted.

Do not let every reviewer comment create a new RQ.

## Preserve useful assets

Classify old work:
- MAIN
- REINTERPRET
- RERUN
- APPENDIX
- SEPARATE PAPER
- DROP

## Produce actual revision work

Depending on request, deliver:
- revised Paper Thesis;
- anchor/literature action;
- new analysis plan;
- rewritten sections;
- response letter.

Do not end with only an audit table.

## Response-letter form

`acknowledge → exact change → why it resolves the concern → location/evidence`

Be concise and non-defensive.

## Project memory integration

For a continuing research project, read [references/project-memory.md](references/project-memory.md).

**Read:** `PAPER_STATE.md`; `CONCEPT_LEDGER.md`; `LITERATURE_LEDGER.md`; `EVIDENCE_LEDGER.md`; `FAILURE_MEMORY.md`; `runs/ relevant history`.

**Write/update:** `RUN_LOG`; `FAILURE_MEMORY.md`; `RESET_REQUEST / PAPER_STATE.md after accepted changes`; `revised manuscript/evidence plans`.

**Constraint:** Treat deep advisor/reviewer comments as research-architecture signals before line edits.
