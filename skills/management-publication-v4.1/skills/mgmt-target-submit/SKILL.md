# Target and Submit

Move a manuscript to a sensible submission.

## Do not fabricate journal facts

Read [references/source-honesty.md](references/source-honesty.md).

Verify current:
- scope;
- submission rules when consequential;
- recent comparable papers;
- formatting or declarations if requested.

Do not state acceptance rates, review times, word limits, or policies from memory when current accuracy matters.

## Define paper identity from frozen state

Summarize:
- core RQ;
- primary literature;
- paper archetype;
- novelty delta;
- evidence strength;
- claim boundary.

Do not redesign the paper merely to fit a prestigious journal.

## Build A/B/C target sequence

Evaluate:
- topic fit;
- theoretical depth;
- design/method expectations;
- empirical scale;
- contribution threshold;
- writing/architecture;
- practical constraints.

Use:
- A: ambitious but defensible
- B: strongest fit
- C: credible fallback

## Calibrate with real recent papers

Inspect several recent comparable articles, not one.

Extract:
- abstract opening;
- introduction problem progression;
- theory density;
- method justification;
- results sequencing;
- discussion/conclusion endpoint.

Separate:
- observed journal pattern;
- your recommendation.

## Prepare submission package

When requested, draft:
- title/abstract adjustments;
- cover letter;
- contribution statement;
- highlights;
- data/code availability;
- declarations/checklist;
- submission order.

## Shared state

Journal targeting can refine presentation, but it cannot silently change the frozen research object, RQ, constructs, or evidence.

## Project memory integration

For a continuing research project, read [references/project-memory.md](references/project-memory.md).

**Read:** `PAPER_STATE.md`; `LITERATURE_LEDGER.md`; `EVIDENCE_LEDGER.md`.

**Write/update:** `RUN_LOG`; `journal/submission fields in PAPER_STATE.md after a real decision`; `verified journal notes in LITERATURE_LEDGER.md if used`.

**Constraint:** Journal fit can change presentation, not the frozen research object or evidence.
