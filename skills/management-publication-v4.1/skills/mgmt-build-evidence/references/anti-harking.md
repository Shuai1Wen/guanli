# Anti-HARKing / Selective Reporting

## Do not
- hide a null full-sample result after finding a significant subgroup;
- search many subgroups/outcomes and present the surviving one as planned;
- rewrite the original RQ without acknowledging the result-driven change;
- treat a different operationalization as a new theoretical result;
- infer subgroup difference from separate significance stars alone.

## If a post-hoc boundary is theoretically meaningful
1. preserve the original main result;
2. label the boundary discovery as exploratory unless theory/planning predates the analysis;
3. run the correct formal difference/interaction test where appropriate;
4. search the literature for whether that boundary is theoretically meaningful;
5. decide KEEP current thesis, RESET, or SEPARATE PAPER.

## RESET_REQUEST
Use only when new evidence genuinely invalidates the frozen thesis.
Document old thesis, new evidence, proposed thesis, and cost of reset.
