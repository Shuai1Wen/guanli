# Frontier Collision Scan

Before freezing novelty, search recent work for collisions:

1. Same focal X / exposure / antecedent
2. Same Y / outcome
3. Same proposed mechanism
4. Same institutional or national context
5. Same method/measurement delta if that is the contribution

Record:
- `NO MATERIAL COLLISION`
- `PARTIAL COLLISION`
- `FULL COLLISION`

A search miss is not proof of novelty. Use cautious wording unless review/frontier coverage is adequate.

If collision is material:
- narrow the claim;
- change the novelty delta;
- pivot the paper;
- or exit.
