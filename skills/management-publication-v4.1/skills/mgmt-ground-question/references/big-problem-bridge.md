# Big-Problem Bridge

A large opening claim is justified only when each link is explicit:

`Important real/theoretical problem`
→ `management mechanism`
→ `core construct`
→ `empirical measure`
→ `main result`
→ `implication for the large problem`

Test each arrow in one sentence.

If any arrow requires an unsupported leap, reduce the opening claim.

"重大问题说得大" does not mean attaching a national strategy slogan to a small empirical indicator.
