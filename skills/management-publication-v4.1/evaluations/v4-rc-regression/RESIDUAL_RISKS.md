# Residual Risks After v4 RC1

## R1 — True behavioral independence not yet proven
The same conversation has seen the frozen oracle. A fresh evaluator/model is required for a real blind benchmark.

## R2 — PAPER_STATE is protocol-level, not transactional
The platform does not provide a hard database lock. Another agent can still violate `FROZEN_DECISIONS` if it ignores the skill. The explicit RESET protocol reduces but does not eliminate this risk.

## R3 — Literature exhaustiveness cannot be guaranteed
The skill can prevent fabricated gaps and require verification, but no finite search proves no study exists.

## R4 — Paper archetypes can be hybrid
The archetype classifier is a forcing device for research logic, not a taxonomy of all management research.

## R5 — Publication-first can still create sunk-cost pressure
The KEEP/PIVOT/SPLIT/EXIT rule is now explicit, but real use must verify that agents actually choose EXIT when appropriate.

## R6 — Journal calibration depends on access to current papers/rules
If current sources are unavailable, the agent must state the limitation instead of filling with memory.

## R7 — No skill can guarantee acceptance
The suite improves research discipline and manuscript production; editorial judgment remains external.
