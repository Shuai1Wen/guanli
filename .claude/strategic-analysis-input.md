# PSC-Graph省级数据采集战略方案深度分析

## 背景情境
- 项目：政策语义因果图谱（PSC-Graph），需要构建"政策语义→政策意图→产业行为/绩效"端到端体系
- 数据需求：省级政策文本，用于异质时序图学习（HGT+TGAT）和稳健DID因果推断（CS-ATT/SA/BJS）
- 当前状态：31省份中11个已验证可用，20个未验证
- 用户提议：采用"四类分层策略"，追求8-12个高质量样本，而非31省全覆盖

## 核心分析问题

### 问题1：研究设计维度 - 样本充分性评估

DID方法对样本量的要求：
- CS-ATT/Sun-Abraham/BJS方法的统计效力如何随样本量变化？
- 8-12个省份是否足以支撑平行趋势检验和稳健性检验？
- 处理组-时点ATT估计需要多少个控制组单元？

图学习对节点多样性的需求：
- HGT+TGAT是否依赖"地理全覆盖"？
- 缺失省份是否导致图结构偏误？
- 8-12个省份能否捕捉核心政策-产业模式？

外部语料补充可行性：
- ChpoBERT等预训练模型能否补充缺失省份？
- 外部语料与自建语料的一致性如何保证？
- 是否引入新的测量偏误？

学术接受度：
- 顶级期刊是否接受"部分省份样本"？
- 如何论证"样本代表性"？
- 缺失省份是否系统性偏向某些特征？

### 问题2：工程可行性维度 - 收益递减分析

当前11个已验证省份的质量：
- 覆盖哪些大区？（华南1、华东4、华北1、华中2、西南2、西北1）
- 是否形成代表性样本？
- 缺失哪些关键区域？（东北全缺、西部仅陕西）

从11扩展到8-12的逻辑：
- 是"优中选优"还是"补充到12"？
- 当前11个中是否有质量问题（如江苏dataproxy.jsp动态接口）？
- 最优策略是什么？

20个未验证省份的收敛难度：
- B类（门户正常但未验证）成功率预估？
- C类（gkmlpt平台）额外工作量？
- D类（访问困难）是否值得硬撬？

时间成本对比：
- 逐个验证20个省份需要多少天？
- 是否值得投入10-20天去收敛？
- 还是深化11个已验证的数据质量更优？

### 问题3：四类分级操作化标准

A类定义（已验证、结构可控）：
- 质量标准：稳定访问、分页清晰、无需JS、时间跨度≥2年
- 处理策略：深化数据质量（增加max_pages、补充解读栏目）
- 优先级：最高

B类定义（门户正常但未验证）：
- 验证策略：按大区优先级、快速验证、成功标准
- 失败处理：降级为C类或D类
- 优先级：中等，按需补充

C类定义（gkmlpt或特殊分页）：
- 特征：动态接口、复杂分页、需要专用解析器
- 处理策略：参考江苏案例、DevTools分析、2-3次尝试上限
- 优先级：低

D类定义（访问困难或禁止）：
- 特征：403/404、JS重、robots禁止、需要登录
- 处理策略：放弃，显性标明缺失
- 补偿方案：外部语料补充、稳健性检验说明
- 优先级：最低

### 问题4：可行路径选择

路径A（保守策略）：
- 从11个中优中选优，排除不稳定的（浙江、江苏？）
- 保留8-10个稳定省份
- 补充1-2个东北/西部B类
- 最终10-12个核心样本

路径B（平衡策略）：
- 保留全部11个已验证
- 优先验证东北2个（辽宁、黑龙江）+ 西部2个（贵州、甘肃）
- 形成13-15个核心样本
- 覆盖7-8个大区

路径C（激进策略）：
- 批量验证20个未验证中的B类
- 追求16-20个样本
- 问题：边际收益递减、可能引入不稳定数据源

### 问题5：风险评估

风险1：B类验证失败率高
- 兜底：接受11-12个样本 + 强化时间维度（延长到10年）
- 兜底：外部语料补充图学习特征

风险2：A类后续访问失败
- 兜底：SHA256校验 + 定期监控 + B类补充

风险3：审稿人质疑代表性
- 兜底：加权分析（GDP/R&D占比）+ 子样本分析 + 安慰剂检验

风险4：图结构破碎
- 兜底：虚拟节点 + 降低地理权重 + 子图学习

## 需要输出的分析结果

1. 战略方案合理性评分（0-10分）及支持理由
2. 推荐执行路径（A/B/C）及详细论证
3. 四类分级的具体操作标准
4. 关键成功要素识别
5. 风险缓解措施
